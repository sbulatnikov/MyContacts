# MyContacts

Аддон для «Аллодов Онлайн»: записная книжка игроков прямо в игре — отметки, заметки, история ников и гильдий
и предупреждение в чат, если рядом снова тот, кого вы пометили отрицательным.

![Окно MyContacts](release/promo/MyContacts-01-cover.png)

Версия 0.9.2 (бета). Автор — NoMercy.

## Что умеет

- **Сам ведёт базу.** Записывает участников вашей группы и отряда, собеседников в личке и написавших в чат.
  Персонаж узнаётся по постоянному ID игры, а не по нику. Любого игрока можно добавить и вручную — по нику или из цели.
- **Карточка игрока.** Отметка (нейтральный, положительный, отрицательный), заметки с датой, гильдия и ранг,
  история ников и гильдий.
- **Предупреждения.** Отрицательный игрок вступил в вашу группу, отряд или гильдию либо пишет вам в личку —
  в чат приходит сообщение, которое видите только вы. Пока он в группе, на кнопке аддона горит красная метка.
- **Смена ника.** Сменил ник — карточка, отметка и заметки остаются с ним, прежний ник уходит в историю.
- **Поиск и фильтры.** Поиск по текущим и прежним никам, фильтры по отметкам, заметкам и встречам за 24 часа.

Все данные хранятся только у вас на компьютере, в настройках аддона, и никуда не передаются.

Полное описание — [release/description.html](release/description.html), список изменений —
[release/changes.md](release/changes.md).

## Установка

1. Скачайте `MyContacts.pak` со страницы [Releases](../../releases).
2. Положите файл в `<папка игры>\data\Mods\Addons\`. При обновлении новый файл заменяет прежний.

## Команды чата

| Команда | Что делает |
| --- | --- |
| `/mc` | открыть окно |
| `/mc add` | карточка игрока, который у вас в цели |
| `/mc add Ник` | добавить игрока вручную |

## Ограничения

- Согильдийцы, друзья и игроки рядом приходят без ID. Предупреждение о вступлении в гильдию работает по нику.
- Игроков, которые просто пробежали мимо, аддон не записывает: ID у них нет. Если такой игрок уже есть в базе,
  при встрече обновляются класс, рейтинг экипировки, гильдия и ранг.
- Смену ника аддон видит, когда игрок с новым ником окажется в группе, отряде или напишет в чат. Если игрок добавлен
  вручную и ещё ни разу не встречался, связать его старый и новый ник нельзя.
- Рейтинг экипировки не читается в PvP-активностях, где игра закрывает его для аддонов.
- База общая для всех персонажей на компьютере.

## Нашли ошибку

Заведите [issue](../../issues): версия аддона, сервер, что делали и что получилось. Ошибки аддона игра пишет
в `Personal\Logs\mods.txt` — приложите строки с `MyContacts`.

# Разработчикам

## Что где лежит

```
lua/       скрипты в UTF-8 (при сборке переводятся в Windows-1251)
             LibDnD.lua  перетаскивание окон и кнопки (уже в Windows-1251)
             Util.lua    строки, чат, время, кэш виджетов
             Config.lua  настройки
             DB.lua      база игроков — без интерфейса
             Game.lua    что приходит от игры: группа и отряд, гильдия, чат, игроки рядом, осмотр
             UI.lua      кнопка, окно, карточка игрока, настройки
             Main.lua    запуск, события, реакции, команды чата
             Probe.lua   только отладочная сборка: пишет в mods.txt, что приходит в событиях
gen/       генератор ресурсов
             build.py    виджеты, тексты, текстуры DXT5
             assemble.py папка аддона целиком + проверка ссылок между файлами
             pak.py      папка аддона -> MyContacts.pak (ZIP с путями Mods/Addons/MyContacts/...)
             tex.py, xdb.py  текстуры и описания виджетов
tools/     strip_debug.py — вырезает отладку из скриптов при сборке
           render.py — грубый предпросмотр окна в PNG по собранным описаниям виджетов
test/      прогон скриптов на заглушках API игры
release/   описание, краткое описание, список изменений и карточки текущего выпуска
_unused/   виджеты прежних версий, которые в выпуск не входят
```

## Сборка

Нужны Python 3 с `numpy` и `Pillow` и `rsvg-convert` (пакет `librsvg2-bin` в Debian и Ubuntu).

```
python3 gen/assemble.py                                    ->  out/MyContacts — папка аддона
python3 gen/pak.py out/MyContacts out/MyContacts.pak       ->  файл для data\Mods\Addons
```

Версия задаётся в одном месте — `MC.VERSION` в `lua/Util.lua`. Имя аддона в игре («MyContacts v0.9.2») и `<version>`
в описании аддона генератор берёт оттуда.

Отладочная сборка — с переменной `ALLODS_DEBUG=1`: в ней остаются блоки `--@debug … --@end`, строки с `--@debug`
в конце и модуль `Probe.lua` (журнал в `mods.txt`, команда `/mc debug`). Обычная сборка их вырезает, оставляя пустые
строки, — номера строк в ошибках совпадают с исходниками. В выпуск отладка не попадает.

## Тесты

```
sh test/run.sh
```

Скрипт вырезает отладку и прогоняет логику аддона на заглушках API игры — дважды: обычная сборка и отладочная.
Нужны Python 3 и `texlua`, `lua5.3` или `luajit` (свой интерпретатор — `LUA=<путь>`). Те же проверки запускаются
в GitHub Actions на каждый pull request.

## Правила кода

- `pcall` не используем. Ожидаемый сбой обрабатывается проверкой перед вызовом или событием игры; над проверкой —
  комментарий `-- Ожидаем: <что может не получиться> — <что делаем>`. `xpcall` — только если функция игры падает
  в обычной ситуации и иначе нельзя, с комментарием `-- Почему xpcall: …`.
- Всё неожиданное не прикрываем: оно падает в `mods.txt` со стеком, и это ошибка аддона.
- Логика (`DB.lua`, `Game.lua`) не трогает виджеты, интерфейс (`UI.lua`) не вызывает игровые действия напрямую.
- Виджет меняется, только если значение изменилось; никаких действий в каждом кадре, опроса по таймеру нет.
- В `lua/` — только символы, которые есть в Windows-1251.

## Ветки и выпуски

`main` — только выпущенное. Доработка — в ветке `feature/<коротко>` или `fix/<коротко>` и через pull request.
Выпуск — слияние в `main` и тег `v<версия>`. Когда тег отправлен на GitHub, выпуск создаётся сам: проверки, сборка,
`MyContacts.pak` и описание из раздела «Изменения <версия>:» в `release/changes.md`. Версия в теге должна совпадать
с `MC.VERSION`; до версии 1.0 выпуск помечается как предварительный.

## Где что хранится

Общие секции настроек (одни на всех персонажей этого компьютера):

```
MyContacts          mc = { ... } — настройки; остальное — положения окон и кнопки (LibDnD)
MyContacts_Meta     формат базы (v = 2) и словари: серверы, зоны, классы, гильдии
MyContacts_DB_NN    записи игроков, одна строка на игрока; 64 куска (NN), кусок выбирается по ключу записи
MyContacts_Cards    отметка, заметки, история ников и гильдий — только у игроков, у которых они есть
```

Ключ записи — `U<id>` (постоянный ID персонажа) или `N<ник>@<номер сервера>` для добавленных вручную, пока ID
неизвестен. Если формат базы в `MyContacts_Meta` не совпадает с текущим, база при загрузке очищается.
