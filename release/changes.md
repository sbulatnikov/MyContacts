Кратко: Записная книжка игроков: отметки и заметки

Изменения 0.9.5:
- В карточке игрока — рейтинг арен 3х3 и 6х6 за текущий сезон: счёт, место, победы и игры, доля побед. Записывается при встрече с игроком.
- Правый клик по кнопке аддона открывает карточку игрока, который у вас в цели.
- В блоке «Гильдии» карточки видны четыре строки, остальные — колесом.
- База при обновлении не очищается.

Изменения 0.9.4:
- Исправлено: окно аддона больше не прячется за рамками, баффами и другими элементами интерфейса — теперь оно рисуется поверх них.

Изменения 0.9.3:
- В карточке игрока — игровая эмблема его класса.
- Аддон запоминает классы, на которых встречал игрока: в карточке ряд эмблем, текущий класс первым, прежние приглушены (до шести).
- Заметки показываются целиком: блок подстраивается под текст, заметка в 300 знаков больше не обрезается.
- Поле ввода заметки стало многострочным; Enter по-прежнему сохраняет.
- База при обновлении не очищается.

Изменения 0.9.2:
- Код без перехвата ошибок (pcall): вместо него — проверки перед вызовами игры по документации API.
- Убраны отладочный режим (/mc debug) и калибровка лички (/mc calib).
- Рейтинг экипировки и осмотр не запрашиваются в PvP-активностях, где игра их закрывает для аддонов.
- В описании: данные хранятся только локально и никуда не передаются.
- Имя аддона в менеджере дополнений — с версией.
